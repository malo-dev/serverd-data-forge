What this server does

  • Relays live JSON Workbench collaboration sessions (document edits, chat, shared files) between browser tabs joined to the same 4-digit tunnel code.
  • Relays presence and remote-control requests for the Data Forge Native Agent, an early-preview desktop companion that lets a tunnel participant ask to control another connected device — only after that device's own user explicitly approves.
  • Nothing is ever written to a database here. A tunnel's data exists only as long as the tunnel is open.

Native Agent — preview status

The remote-control agent (screen sharing, mouse/keyboard, remote terminal) is an early test build: unsigned, not yet hardened, and not intended for general distribution. Every remote-control action requires the target device's explicit, per-session consent — nothing runs without it.
